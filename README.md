# Izdevumu izsekotājs

Šī ir vienkārša Python programma, kas ļauj sekot līdzi saviem izdevumiem.

## Funkcijas:

* Pievienot izdevumus (datums, summa, kategorija, apraksts)
* Apskatīt visus izdevumus
* Dzēst izdevumus
* Filtrēt pēc mēneša
* Redzēt kopsavilkumu
* Eksportēt datus CSV failā
* Saglabāt datus JSON failā

## Kā palaist programmu:

1. Atver termināli
2. Aizej uz projekta mapi
3. Ieraksti:

python app.py

## Failu struktūra:

* app.py — galvenā programma
* logic.py — loģika
* storage.py — saglabāšana JSON
* export.py — CSV eksports
* docs/DEVLOG.md — izstrādes žurnāls
